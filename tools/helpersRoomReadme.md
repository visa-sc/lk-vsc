# Памятка для Claude Андрея Петрова: комната «Помощники Андрей-Андрей»

## Что это
Комната в чате work.voyotravel.ru. Участники: Андрей Комисаренко (директор), Андрей Петров, «Помощник Андрея» (Claude директора) и «Помощник Петрова» — это вы.
Через эту комнату два Claude сообщают друг другу о своих правках, чтобы не затирать чужую работу. Сюда же идут просьбы к другой стороне. Так же устроено с Екатериной Зайцевой и её Claude.

## Доступ
Тот же личный ключ, что и для `/data-api`: заголовок `X-RO-Key: <ключ>`. Адрес: `https://voyotravel.ru`. Ключ в комнату не писать.

```bash
# сообщения после отметки (ISO-время последнего прочитанного; без since — последние 200)
curl -s -H "X-RO-Key: $KEY" "https://voyotravel.ru/data-api/room/messages?since=2026-11-19T00:00:00.000Z"
# файл из сообщения (id из поля files)
curl -s -H "X-RO-Key: $KEY" -o file "https://voyotravel.ru/data-api/room/file/<id>"
# написать в комнату (от имени «Помощник Петрова»); key — необязательная метка от двойной отправки
curl -s -H "X-RO-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"text":"Выложил …: что и зачем","key":"deploy-2026-11-20-1"}' https://voyotravel.ru/data-api/room/say
```
Ответ messages: `{ messages: [{id, at, from, name, text, files:[{id,name,size}]}], last }`. `last` сохраняйте у себя — это отметка для следующего раза.
Ограничения: не длиннее 4000 знаков за сообщение, не больше 30 сообщений в час. Другие комнаты этим ключом не видны.

## Что делать
1. **Каждую ночь в 01:00 МСК** читать новые сообщения с прошлой отметки. Правки стороны Андрея, особенно в ваших зонах (visa-sc.ru, spb, ekb, eSIM, поддержка), — учитывать и не откатывать своими выкладками. Настройте это расписанием у себя (cron или расписание Claude Code), отметку храните в файле.
2. **После каждой своей выкладки** коротко пишите в комнату: что поменяли (сайт, страница или файл) и зачем. Помощник Андрея читает комнату каждую ночь в 01:40 и складывает ваши записи в свой журнал правок.
3. **Просьбы к стороне Андрея** — сюда же, одним сообщением с сутью. Срочное — Андрею лично.
4. Секреты (ключи, пароли, токены) и персональные данные клиентов в комнату не писать.

## Свежие правки стороны Андрея, которые касаются вас (19.11.2026)
- **Вход на сервер по SSH — только по ключам** (пароль отключён). Ваш вход по ключу работает как раньше.
- **Брошенные формы:** такие заявки теперь уходят в amo как обычные «Новая заявка № … (Заявка)». Проверки форм без настоящего браузера (headless) заявок больше не создают. Автотесты форм запускайте с «HeadlessChrome» в User-Agent: так они не попадают в статистику и в заявки.
